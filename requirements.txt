# Authlib>=1.3.2 but does not depend on it, so it has to be listed explicitly.
#
# DO NOT DOWNGRADE BELOW 1.6.12. Authlib is what verifies the Cognito ID token
# signature, and everything below that carries open advisories against exactly
# that job -- including a CRITICAL JWS/JWK header-injection signature-
# verification bypass and a fail-open OIDC hash binding flaw (both patched in
# 1.6.9), plus an open redirect patched in 1.6.12. A vulnerable Authlib means
# the login gate can be bypassed, not merely that a library is out of date.
